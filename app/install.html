Install the Wild2Commons extension

Checking whether the extension is installed…

Load your eBird photos automatically

The extension finds your eBird account, lists your Macaulay Library photos and fetches the originals, so you don't need the eBird data file or to download photos by hand. It also adds an Upload to Commons button on Macaulay Library, iNaturalist and Xeno-canto record pages, and fills in your iNaturalist username.

Download for Chrome / Edge Download for Firefox

The extension is optional. Wild2Commons works without it; for eBird you then use your eBird data file and add the photo files yourself.

Chrome, Edge, Brave and other Chromium browsers

  1. Download wild2commons-chrome.zip with the button above.
  2. Unzip it into a folder you will keep, for example Documents\Wild2Commons extension. Don't delete this folder afterwards: the browser runs the extension from it.
  3. Open chrome://extensions (Edge: edge://extensions) in the address bar.
  4. Turn on Developer mode (top right; in Edge, in the left panel).
  5. Click Load unpacked and choose the unzipped folder: the one that contains manifest.json.
  6. Come back to Wild2Commons and reload the page. The eBird card now says the extension is installed.

Chrome shows a reminder about developer-mode extensions now and then; that is normal for extensions not installed from the Chrome Web Store.

Firefox

  1. Click Install the signed Firefox add-on.
  2. Firefox asks for permission: click Continue to installation, then Add.
  3. Reload Wild2Commons.

Firefox only keeps add-ons that Mozilla has signed. Until the signed version is available here, install it for the current session:

  1. Download wild2commons-firefox.zip with the button above and unzip it.
  2. Open about:debugging#/runtime/this-firefox in the address bar.
  3. Click Load Temporary Add-on… and choose manifest.json in the unzipped folder.
  4. Reload Wild2Commons.

A temporary add-on is removed when Firefox closes; repeat the steps next time. Firefox Developer Edition and Nightly can keep it permanently after setting xpinstall.signatures.required to false in about:config.

Updating

When this page shows a newer version than the one installed, download it again, unzip it over the old folder, and press the reload arrow on the extension in chrome://extensions (Firefox: load it again).

What the extension can see

  • It works on eBird, Macaulay Library, iNaturalist, Xeno-canto and the Wild2Commons website only.
  • It opens your eBird photo list and photo pages in background tabs and closes them afterwards, and uses "Download original" on your own photos.
  • It keeps no passwords or sign-in tokens and sends nothing anywhere except to the Wild2Commons page open in your browser.
  • The code is public: extension folder on GitHub.
